📖 What This Application Does

Video Prediction Policy 2 is a research-grade application that watches a video sequence, predicts what will happen next, and then chooses the best action based on that prediction. In everyday terms, it is a "look ahead and decide" tool. Instead of reacting only to what is happening right now, it uses the future it expects to see, which usually results in smarter and steadier decisions.

The project is shared openly so that anyone — students, hobbyists, researchers, or curious beginners — can download it, run it on a normal Windows computer, and see the results for themselves. The application runs locally on your machine. You do not need an account, a subscription, or a cloud service to use it.

✨ Key Features

  • Future-aware prediction: The application looks at a short video clip and forecasts the frames that come next.
  • Action selection: Based on those forecasts, it recommends the most suitable action instead of guessing blindly.
  • Official implementation: This is the original code released by the authors, so you get the same behaviour described in the project documentation.
  • Simple Windows workflow: One download, one extraction or launch, and you are running.
  • Reusable components: The prediction and policy parts are kept separate, so you can experiment with each one independently.
  • Clear sample data: Example sequences are included so you can test the application immediately without preparing your own files.
  • Readable output: Results are presented in plain terms, with predicted frames and the suggested action shown side by side.
  • Active project: Improvements and fixes are published through the same official page you download from.

🛠️ Troubleshooting

Most problems have a simple cause. Work through the points below if something does not behave as expected.

  • The application does not open: Confirm that all downloaded files are in the same folder and that nothing was moved or renamed.
  • Windows blocks the file: Right-click the file, open its properties, and allow it to run. Then try again.
  • The window appears blank: Close the application completely, then reopen it. Allow a little extra time on the first launch.
  • Processing is very slow: Close other heavy programs such as browsers with many tabs, and make sure your computer is plugged in and not in battery-saving mode.
  • The download stops partway: Delete the partial file and download it again from the official link above.
  • Results look unexpected: Start with the included sample sequences before trying your own files, so you can confirm the application is working correctly.
